# SQL Server – Student Database Management

## Project Overview
This project demonstrates basic SQL Server queries using a Student (STUD) table. It covers data retrieval, filtering, sorting, column aliases, and aggregate functions.

## Database Details
- **Database Name:** STUDENTDB
- **Table Name:** STUD
- **Columns:**
  - SNO – Student Number
  - SNAME – Student Name
  - AGE – Student Age

## SQL Concepts Covered

### 1. SELECT Statement
Retrieves all records from the STUD table.

### 2. WHERE Condition
Filters records based on a specific condition.

### 3. OR Operator
Retrieves records that satisfy either condition.

### 4. AND Operator
Retrieves records that satisfy both conditions.

### 5. Column Alias
Uses alternative names for columns with AS.

### 6. IN Operator
Checks multiple values in a single condition.

### 7. BETWEEN Operator
Retrieves records within a specified range.

### 8. IS NULL
Finds records containing NULL values.

### 9. IS NOT NULL
Finds records that do not contain NULL values.

### 10. ORDER BY
Sorts records in ascending and descending order.

### 11. DISTINCT
Retrieves unique values.

### 12. LIKE Operator
Searches for records matching a specified pattern.

## Aggregate Functions
- COUNT() – Counts the total number of records.
- MAX() – Finds the maximum age.
- MIN() – Finds the minimum age.
- AVG() – Calculates the average age.
- SUM() – Calculates the total age.

## How to Execute
1. Open SQL Server Management Studio.
2. Connect to your SQL Server.
3. Select the STUDENTDB database.
4. Open a New Query window.
5. Execute the SQL queries.
6. View the output in the Results section.
